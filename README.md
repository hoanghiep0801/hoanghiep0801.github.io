# Hoang Hiep — Portfolio

Static portfolio website. The editable website is in `dist/`; no build step is required.

## Deployment

Enable **Settings → Pages → Source: GitHub Actions** for this repository.
Push website changes to `main` to publish, or run **Publish portfolio** manually
from the Actions tab. The workflow deploys only `dist/`.

Project pages and artwork credits are included in the website. The current
development version asks search engines not to index it.
